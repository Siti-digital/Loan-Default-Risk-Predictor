Project Overview & Research Question

Core Research Question: Do macroeconomic indicators (civilian unemployment rate, 6-month unemployment change, CPI inflation) significantly improve retail loan default prediction compared to traditional credit models relying strictly on individual borrower profiles?

Unit of Analysis Single 36-Month Loan
Temporal Leakage Check 2-Month Publication Lag
Validation Method Out-of-Time 2015 Holdout
Target Objective Calibrated PD: P(Y=1|X)

Experimental Model Architecture

Models are strictly separated to isolate the marginal predictive power of macroeconomic conditions at origination:

Model A

Historical Baseline

Predicts empirical training base-rate default probability (uninformed baseline).

Model B

Borrower-Only Logit

Application features at origination. Excludes lender pricing (int_rate, installment, grade).

Model C

Borrower + Macro Logit

Borrower attributes plus conservative 2-month lagged stationary macro series (UNRATE, change, CPI).

Model D

Borrower + Macro LightGBM

Gradient boosted trees on Model C features to capture potential non-linearities. Evaluated separately in Python.

2015 Holdout Test Scorecard (Untouched Out-of-Time Evaluation)

Trained chronologically on 2007–2014 loans; evaluated on 283,026 loans from the 2015 holdout vintage (Empirical Default Rate = 14.89%).

Origination-Time Macroeconomic Sensitivity & What-If Explorer

Adjust origination-time macroeconomic condition levers below. Holding borrower characteristics constant, this tool computes the model-estimated Probability of Default (PD) for Model C (Borrower + Macro Logistic Regression) using the client-side logistic sigmoid engine:

P(Default) = 1 / (1 + e-(β₀ + Σ βᵢ · (Xᵢ - μᵢ) / σᵢ))

Note: Preprocessing means (μ) and standard deviations (σ) along with linear weights (β) are strictly derived from Model C. Model D (LightGBM) is a non-linear gradient-boosted decision tree ensemble evaluated offline in Python benchmarks; it is not represented by linear coefficients or sigmoid approximations.

Methodological & Econometric Scope Disclaimers

  • Not a Lifetime Forecasting Tool: This model estimates default probability based strictly on economic conditions prevailing at origination. It does NOT predict how an active loan performs if unemployment spikes 18 months into repayment (a hazard model with time-varying covariates is required for lifetime trajectory stress testing).
  • Observational Association, Not Causality: Estimated coefficients capture predictive associations across vintages and do not establish causal treatment effects.
  • Interpolation Only: Slider ranges are strictly clamped to the empirical historical bounds observed during the 2007–2014 training window to prevent ungrounded extrapolation.

Methodology & Statistical Defenses

Rigorous Out-of-Time (OOT) Split

Avoids standard random K-Fold cross-validation which leaks temporal dependencies. Trains chronologically on 2007–2014 (including the Great Recession shock) and validates out-of-time on the fully matured 2015 cohort (0.05% unresolved rate).

Zero Look-Ahead Macro Alignment

Macro series are shifted by a conservative 2-month publication lag, ensuring that loans originated on the 1st of month t receive macroeconomic data published and verified available prior to origination.
